��� CSRF IMPLEMENTATION DETAILS
─────────────────────────────────────────────────────────────────────────────
1. Get CSRF Token (public endpoint)
   GET /api/v1/csrf-token
   Response includes: X-CSRF-Token header

2. Use CSRF Token (in all requests)
   -H "X-CSRF-Token: {token}"
   -b cookies.txt (maintain session)

3. Authenticate with CSRF
   POST /auth/login
   -H "X-CSRF-Token: {token}"
   Response: JWT Bearer token

4. Make API Calls with Both
   -H "Authorization: Bearer {jwt}"
   -H "X-CSRF-Token: {token}"
   -b cookies.txt


���️ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Services not running?
  → docker-compose up -d
  → Wait 10 seconds
  → Check: docker-compose logs -f

Tests show 404?
  → Verify jobs backend is running
  → Check: curl http://localhost:3000/healthz

CSRF token not obtained?
  → Verify API is accessible
  → Check: curl http://localhost:3000/api/v1/csrf-token

Authentication fails?
  → Check auth service: curl http://localhost:3001/api/v1/health
  → Verify credentials in environment variables
  → Test with mock token if auth service down

File downloads fail?
  → Create resume first (Test 5)
  → Check file permissions
  → Verify ~/resume-data directory exists
